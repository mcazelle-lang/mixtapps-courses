# 🛒 Liste de courses

Ta liste de courses rangée par rayon : ajoute, coche dans les allées, vide le panier en un clic et copie la liste pour l’envoyer à qui tu veux.

- **Essayer** : https://mixtapps-demos.web.app/courses/
- **Sur Mixtapps** : https://mixtapps.com/u/ines-moreau/OUExwuJUQK6ZI2FAwmay (app de démonstration du compte Inès Moreau)
- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
